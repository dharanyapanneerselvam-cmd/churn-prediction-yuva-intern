# Customer Churn Prediction System

Week 1 Task submission for **Yuva Intern – Science Project Coordinator** internship.

## Overview
This repository contains the technical skeleton for a Python-based customer
churn prediction pipeline, accompanying the Week 1 Project Plan & Strategy
document submitted separately as a Word report.

## Project Phases
1. **Discovery & Scoping** – define churn target and business KPIs
2. **Data Strategy** – ingest and clean customer data (`load_data`, `clean_data`)
3. **Technical Planning** – feature engineering and model pipeline
   (`encode_categoricals`, `build_pipeline`)
4. **Model Training & Evaluation** – Random Forest classifier
   (`train_model`, `evaluate_model`, `plot_feature_importance`)
5. **Documentation & Sign-off** – see the Week 1 project plan report

## Tech Stack
- Python 3
- pandas, numpy
- scikit-learn
- matplotlib

## How to Run
```bash
pip install pandas numpy scikit-learn matplotlib
python churn_prediction_pipeline.py
```
